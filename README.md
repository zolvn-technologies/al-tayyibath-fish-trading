# Al Tayyibath Legacy

Create a **premium, sophisticated, editorial single-page corporate website** for **Al Tayyibath Fish Trading Company LLC**, an established seafood trading and fish processing company based in Abu Dhabi, UAE.

This website is for a real **B2B seafood supplier** serving prestigious customers including royal palaces, five-star hotels, catering companies, supermarkets and other commercial clients.

The final website must feel like a **serious, established UAE seafood company with 40 years of industry experience**, not like an AI-generated landing page, SaaS template, restaurant website, or ecommerce storefront.

This is a **STATIC MARKETING WEBSITE ONLY**.

Do not create:
- backend
- database
- authentication
- dashboard
- CMS
- ecommerce functionality
- checkout
- product pricing
- customer accounts
- fake forms that imply backend functionality
- unnecessary routes

Build the entire homepage as one coherent visual system.
